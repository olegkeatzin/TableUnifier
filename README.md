# TableUnifier

Система автоматического **объединения таблиц** через сопоставление схем (schema
matching) и разрешение сущностей (entity resolution). Дипломная работа.

Веб-приложение запускает **инференс** предобученной GNN/GAT-модели: загружаете
несколько таблиц поставщиков → строится гетерогенный граф → модель находит
дубликаты строк → получаете унифицированную таблицу с экспортом.

---

## Быстрый старт

```bash
# 1. Зависимости (менеджер пакетов — uv, не pip)
uv sync

# 2. Запуск веб-приложения (бэкенд + фронт на одном порту)
uv run python -m table_unifier.server.main --host 0.0.0.0 --port 8000

# 3. Открыть http://localhost:8000/
```

Перед запуском убедитесь, что доступны:

- **Ollama** по адресу из `OllamaConfig.host` — нужна для эмбеддингов столбцов
  (`qwen3-embedding:8b`). В проекте Ollama/GPU живёт на удалённом nvidia-server;
  локально не поднимается. Если Ollama недоступна, сборка графа вернёт понятную
  ошибку в журнал сборки (экран 2), а не упадёт молча.
- **Чекпоинт** `output/bge-m3/v14_mrl_gat_model.pt` (+ опц. `.config.json` рядом).
- CUDA желательна, но при её отсутствии — CPU-fallback с предупреждением.

## Дефолтный пример

В папке [`examples/`](examples/) лежат две готовые таблицы автомобилей разных
поставщиков — перетащите их в зону загрузки на первом экране:

| Файл | Строк | Особенности |
|------|-------|-------------|
| `supplier_a.xlsx` | 11 | `color` текстом (`чёрный`), `bodyType` по-русски (`седан`) |
| `supplier_b.xlsx` | 11 | `color` в HEX (`#000000`), `bodyType` по-английски (`Sedan`), колонки `mileage_km` / `price_rub` |

(те же данные продублированы в `.csv` — приложение принимает `.xlsx`, `.csv`, `.parquet`).

Пример специально содержит:

- **8 настоящих дубликатов** — одна и та же машина у двух поставщиков с разным
  форматированием значений (их модель должна объединить);
- **по 3 уникальные строки** в каждой таблице (должны остаться синглтонами);
- **форматные расхождения** значений (`color`: текст vs HEX) — подсвечиваются на
  экране ревью;
- **переименованные столбцы** (`mileage`→`mileage_km`, `price`→`price_rub`) —
  детектируются на этапе schema-divergence.

Ожидаемый результат: из 22 исходных строк → ~14 сущностей (8 объединённых пар + 6 одиночных).

## Пайплайн (5 экранов)

1. **Источники** — загрузка таблиц, превью, callout о расхождениях схем.
2. **Гетерогенный граф** — узлы строк + токенов, рёбра несут эмбеддинги столбцов
   (qwen3, MRL-truncated до 1024). Считается через `dataset/embedding_generation`
   и `dataset/graph_builder`.
3. **Инференс GNN** — прямой проход `EntityResolutionGAT`, попарное косинусное
   сходство, компоненты связности. Панель «время выполнения» показывает тайминги
   стадий (описания/эмбеддинги столбцов, эмбеддинги строк, GAT) и память графа.
4. **Ревью пар** — ручная проверка кандидатов, слайдер порога, approve/reject.
5. **Результат** — унифицированная таблица с раскрытием членов кластера + экспорт
   в `.xlsx` / `.csv` / `.parquet`.

## Архитектура

```
Frontend (React+CSS через CDN, без сборки)  ──REST/WebSocket──►  FastAPI + uvicorn
  src/table_unifier/server/static/                               src/table_unifier/server/
                                                                   ├─ routes/   (sources, graph, infer, clusters, export)
                                                                   ├─ services/ (inference, progress, storage)
                                                                   └─ main.py   (create_app + StaticFiles)
                                                                          │ вызывает существующий pipeline
                                                                          ▼
                                            dataset/embedding_generation · dataset/graph_builder ·
                                            models/entity_resolution (GAT) · evaluation/clustering
```

Серверный код изолирован в `src/table_unifier/server/` и не трогает остальной
pipeline (эксперименты, обучение). Приложение — **только для инференса**.

### API (всё под префиксом `/api`)

| Метод | Путь | Назначение |
|-------|------|-----------|
| POST | `/sources/upload` | загрузка таблиц + schema-divergence |
| POST | `/graph/build` | построение HeteroData (async) |
| GET | `/runs/{id}/graph` | граф для визуализации |
| GET | `/runs/{id}/embeddings` | UMAP-проекция эмбеддингов строк |
| POST | `/infer/run` | запуск инференса (async) |
| POST | `/infer/single_pair` | сходство пары при заданном пороге |
| GET | `/runs/{id}/clusters` | кандидаты + кластеры + метрики |
| POST | `/runs/{id}/clusters/decisions` | пользовательские approve/reject |
| GET | `/runs/{id}/unified.{xlsx\|csv\|parquet\|json}` | экспорт |
| WS | `/ws/runs/{id}/stream?kind=build\|infer` | стрим прогресса |
